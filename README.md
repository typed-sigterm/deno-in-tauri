# Deno in Tauri ![Last Commit](https://img.shields.io/github/last-commit/typed-sigterm/deno-in-tauri/main) ![License](https://img.shields.io/github/license/typed-sigterm/deno-in-tauri) ![OSS Lifecycle](https://img.shields.io/osslifecycle?file_url=https%3A%2F%2Fraw.githubusercontent.com%2Ftyped-sigterm%2Fdeno-in-tauri%2Fmain%2FOSSMETADATA) [![GitHub Stars](https://img.shields.io/github/stars/typed-sigterm/deno-in-tauri)](https://github.com/typed-sigterm/deno-in-tauri)

Run JavaScript/TypeScript code with Deno Core Engine, in Tauri apps.

This project is mainly an example, not a standalone app. Checkout [`lib.rs`](./src-tauri/src/lib.rs) for the core logic.

> [!WARNING]
> Because [Deno will cease maintenance](https://deno.com/blog/cloudflare#:~:text=After%20that%20year%20we%20will%20end%20our%20development%20of%20the%20Deno%20runtime), the project is no longer maintained by [Typed SIGTERM](https://typed-sigterm.me). If you're interested in it, feel free to fork.
